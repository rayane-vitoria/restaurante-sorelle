# Restaurante Sorelle

Projeto acadêmico de extensão desenvolvido com o objetivo de fortalecer a presença digital do Restaurante Sorelle por meio de um site institucional.

## Sobre o projeto

O site foi desenvolvido para centralizar informações relevantes do estabelecimento em uma plataforma web, proporcionando uma navegação organizada, intuitiva e agradável aos usuários.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Objetivo

Aplicar conhecimentos de desenvolvimento web na criação de uma solução digital para apoiar a presença online de um estabelecimento local.
